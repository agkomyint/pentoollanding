# Pentool web brand

## Position

Pentool is open design infrastructure for humans and agents: one native binary, a visual canvas, a precise CLI, and readable `.pen` source files. The voice is direct, capable, transparent, and slightly playful. Prefer concrete proof over grand claims.

## Palette

- Ink `#111318` — primary text, dark surfaces, terminal panels
- Paper `#F4F3EC` — main canvas and page background
- Soft paper `#E9E7DC` — secondary sections
- Signal lime `#B8F34A` — brand mark, focus, calls to action
- Muted ink `#66685F` — supporting copy
- Hairline `#CFCDC0` — borders and structure

Lime is a signal, not a wallpaper. Use it for the nib mark, selected state, key CTA, and small moments of emphasis. Maintain dark text on lime.

## Typography

- Geist Sans for interface and display typography
- Geist Mono for commands, file extensions, labels, and metadata
- Display headlines use tight tracking and compact line height; body copy stays relaxed and readable

## Shape and imagery

Use the geometric pen-nib `P` mark from the Pentool repository. UI previews should feel like real editor or terminal surfaces. Borders, grids, and offset shadows communicate construction and editability. Avoid glossy gradients, generic 3D blobs, and decorative stock imagery.

## Writing

- Say “open `.pen` files,” not “revolutionary creative artifacts.”
- Lead with a job the user can complete.
- Pair claims with commands, file formats, or operational details.
- Refer to agents and humans as collaborators using the same source document.
